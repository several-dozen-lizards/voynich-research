# Code for direction fingerprints and directed-origin calibration

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Registered additional generator controls and an origin test that included uncertainty in the inferred direction.

## What we found

The associated follow-up retained generator direction failures and a narrow manuscript-paragraph origin pass, with failures in the longer and Latin origin panels.

## What remains unresolved

One realized generator does not represent every member of its class. Paragraph calibration does not establish transfer to actual circular text.

## What is in this folder

- [PROTOCOL.md](../../research/voynich-lab/extensions/ringdir_followup_v3/PROTOCOL.md): the rules, intended scope, or pinned setup.
- [verify_followup.py](../../research/voynich-lab/extensions/ringdir_followup_v3/verify_followup.py): checks or qualification evidence; read the scope of the gate.
- [run_followup.py](../../research/voynich-lab/extensions/ringdir_followup_v3/run_followup.py): implementation or checking code.
- [test_followup.py](../../research/voynich-lab/extensions/ringdir_followup_v3/test_followup.py): implementation or checking code.
- [registration/](../../research/voynich-lab/extensions/ringdir_followup_v3/registration) (6 archived files): Study rules, source/geometry registration, or pinned inputs. Read the timing and amendment receipts before assuming a stage was complete.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
