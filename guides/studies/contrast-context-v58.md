# Seeing the actual words behind section differences

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Collected the source lines and neighboring words behind the selected controlled word-part contrasts.

## What we found

The concordance makes recurring pairs, triples, alternate readings, and unknown slots inspectable. It describes where the selected patterns occur rather than running a new phrase-significance test.

## What remains unresolved

Recurrence across pages is not automatically more than chance, and neither recurrence nor a section association supplies a meaning.

## What is in this folder

- [RESULTS.json.gz](../../research/contrast-context-v58/RESULTS.json.gz): saved data or supporting evidence; field definitions come from the protocol/report.
- [VERIFICATION.json](../../research/contrast-context-v58/VERIFICATION.json): checks or qualification evidence; read the scope of the gate.
- [report.html](../../research/contrast-context-v58/report.html): explanation, outcome, or dated checkpoint.
- [SUMMARY.json](../../research/contrast-context-v58/SUMMARY.json): saved data or supporting evidence; field definitions come from the protocol/report.
- [app.js](../../research/contrast-context-v58/app.js): implementation or checking code.
- [build.py](../../research/contrast-context-v58/build.py): implementation or checking code.
- [data.js.gz](../../research/contrast-context-v58/data.js.gz): saved data or supporting evidence; field definitions come from the protocol/report.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
