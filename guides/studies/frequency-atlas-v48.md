# A browser for manuscript word parts

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Built filters and concordances for written characters, candidate sign groups, prefixes, suffixes, strings, and complete words.

## What we found

The atlas makes distributions inspectable by hand, section, format, and line position, while keeping the two main readings separate and treating unknown words as barriers.

## What remains unresolved

This is an exploration tool, not automatic interpretation. Overlapping strings are not independent categories, and section differences do not identify meanings.

- [verify.py](../../research/frequency-atlas-v48/verify.py): checks or qualification evidence; read the scope of the gate.

- [SHA256SUMS.json](../../research/frequency-atlas-v48/SHA256SUMS.json): saved data or supporting evidence; field definitions come from the protocol/report.
- [build.py](../../research/frequency-atlas-v48/build.py): implementation or checking code.
- [data.js.gz](../../research/frequency-atlas-v48/data.js.gz): saved data or supporting evidence; field definitions come from the protocol/report.
- [rows.json.gz](../../research/frequency-atlas-v48/rows.json.gz): saved data or supporting evidence; field definitions come from the protocol/report.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
