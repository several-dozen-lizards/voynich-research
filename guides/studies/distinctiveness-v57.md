# Which written forms distinguish manuscript sections?

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Turned the earlier controlled word-part comparisons into a searchable ranking and inspection interface.

## What we found

The display retains the earlier twenty-one paired passing contrasts alongside direction disagreements, rare untested forms, and unsupported comparisons. It adds navigation rather than a new experiment.

## What remains unresolved

A distinctive form is not a decoded meaning. Comparable spatial data were too sparse to treat inside/on/outside rankings as established location effects.

## What is in this folder

- [RESULTS.json.gz](../../research/distinctiveness-v57/RESULTS.json.gz): saved data or supporting evidence; field definitions come from the protocol/report.
- [VERIFICATION.json](../../research/distinctiveness-v57/VERIFICATION.json): checks or qualification evidence; read the scope of the gate.
- [report.html](../../research/distinctiveness-v57/report.html): explanation, outcome, or dated checkpoint.
- [PROVENANCE.json](../../research/distinctiveness-v57/PROVENANCE.json): source attribution, access history, or rights context.
- [app.js](../../research/distinctiveness-v57/app.js): implementation or checking code.
- [build.py](../../research/distinctiveness-v57/build.py): implementation or checking code.
- [data.js.gz](../../research/distinctiveness-v57/data.js.gz): saved data or supporting evidence; field definitions come from the protocol/report.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
