# C16-KH — Phase 6 decisions (registered before scoring)

This is a documented reimplementation/extension, not a byte-identical reproduction. No manual spelling correction or translation is permitted. Do not rate blind outputs. Existing Phase 4/5 files are read-only inputs.

## Published method and unavoidable differences

Hauer & Kondrak (2016), TACL 4:75–86, https://aclanthology.org/Q16-1006/ §§4–5: frequency-initialized substitution; decomposition-pattern word uni/bi/trigram mutations; beam search with character and word trigram models on alphagrams; exact alphagram candidate emission; trigram Viterbi with deleted interpolation. Their Voynich runs fit pages separately. They print no full letter key, use a 35-symbol Currier transcription, and name Tanach without an edition/URL. The first-line example cannot establish a complete key and will not be used as a constraint.

Author software homepage returned 410; index and guessed archive endpoints returned 404; archive index timed out. Retrieval attempts are preserved. Re-derive using the described relationships, with the following explicit engineering choices, fixed before results:

- ZL EVA codepoints are source symbols; no conjectural EVA→Currier conversion, glyph grouping, or source-symbol deletion. Source relabeling is sorted native symbol→shared inventory, injective. Surplus symbols beyond 22 receive distinct dummy targets, never silently vanish or merge. Unknown source codepoints remain invalid words. Comparable target alphabet is Hebrew 22 plus necessary distinct dummies; report actual cardinalities. Alphabet-size mismatch is a limitation, not something injective relabeling can repair.
- Hebrew NFKD; remove combining marks; strip HTML tags; non-Hebrew characters become word separators; normalize five final forms automatically to medial forms. No vowel-letter deletion, stemming, prefix stripping, typo correction, manual reconstruction, or synonym expansion. Identical Hebrew processing for both corpora and all sources. Retain original forms in source files.
- Published exact Tanach edition unavailable: substitute Sefaria `Tanach with Text Only` (public domain, tanach.us source). Medieval arm is all available `Mishneh Torah, ...` `Torat Emet 363`/`370` public-domain volumes in downloaded index. License and completeness checked before admission. This is an edition corpus, not a manuscript-era orthographic reconstruction. No union of arms.
- Train corpus models on first 80% of verses/halakhot per work, hold out last 20% for LM calibration/known-language diagnostics; lexicon uses training only. This held-out separation differs from the original full-corpus models. No corpus sentence spans work boundaries. Remove footnote HTML including its contents before tokenization.
- Re-derived key fitter: frequency initial key; decomposition-equivalent mutations from top 24 observed uni/bi/trigrams and top 3 training counterparts per pattern; frequency pairing within equal cross-word multiplicity signatures; beam width 3, maximum 12 rounds, stop when beam does not improve. Score equal average character-trigram and word-trigram log probability on alphagrams. Fixed add-0.1 character smoothing; deleted-interpolated word trigram with positive 1e-12 floor. These numerical settings and constrained search budget are not supplied by the 2016 paper. No outcome-driven restarts or tuning. Log all winning keys/objectives and search counts. Frequency fallback remains a baseline, not successful key recovery.
- Fit independently by page/document and lexicon, using original row direction; freeze key before direction scoring. This holds substitution constant to isolate reading order; unlike a full per-variant refit, maxima only select reading/decoding variants. C11 clean uses the identically re-derived key from its own corresponding page; equality is verified, not imposed. Report page-specific key inconsistency as well as contextual decoder inconsistency.
- Decoder: exact second-order Viterbi, all candidates (no top-k), singleton `<UNK>` for zero hits, deleted interpolation learned by leave-one-out counts, sentence boundaries at each physical line. For columnar variants, each column is one pseudo-line. No punctuation/syntax parser. Ranking score is mean trigram log probability including unknown penalty and end marker. Unknown unigram probability is assigned training hapax mass; selected strings are model outputs, not evidence of Hebrew fluency. Display final-form normalization identically for every source.

## Frozen variants and selection

24 variants = within-word {LTR,RTL} × word order {LTR,RTL} × physical line order {top-bottom,bottom-top} × traversal {row,column,boustrophedon}. Apply to every source and lexicon. Row: reorder lines then words. Boustrophedon: after physical line order, reverse word order on alternate lines, starting with unchanged first line, in addition to selected word direction. Column: first selected line/word directions, then word-slot k across all successive available lines, skipping absent slots; each k yields a pseudo-line. Approximation only: ZL has no word x-coordinates. Within-word reversal occurs before alphagram conversion; it must be algebraically invariant. Line order is also invariant for independent row-line decoding except boustrophedon parity/column direction. Retain all duplicates in full table and identify them; do not count duplicate maxima as independent evidence.

Per source/lexicon/version/variant: report all-lines token/line scores and top-N mean. Top N=100 for ZL; N=25 per null, bounded by available unique input-unit identities. Deduplicate physical-line identities across variants before top-N; column identities are their constituent slot IDs and remain separate eligible pseudo-lines. Ties by variant ID and source line identity. Per-line maximum across variants precedes top-N selection. Primary contrasts: ZL top-100 maximum score minus each null top-25 maximum score, with full tables; these are descriptive max-statistic controls, not calibrated p-values. Report equal-N=25 sensitivity, and raw token coverage, lengths, and unknown fractions. Each null gets its own maximum, never compared to only its baseline variant. Finite families and unequal length/size prevent a randomization p-value or general discovery claim.

## Metrics and blind set

Dictionary hit = at least one exact alphagram lexicon candidate; report tokens/types and count candidates per token, including zero. Cross-context consistency = pairwise agreement of non-UNK decoded occurrences of a source word in different physical contexts; also report unknown-inclusive agreement and supported pairs. Separate within-key and cross-page comparisons; deterministic repeated lookup alone is not evidence. Candidate sets, mapped forms, chosen output and token provenance retained.

Topic vocabulary is a narrow, authored exact-form probe, frozen below, not a Hebrew semantic classifier. No post-result additions. Botanical: צמח צמחים עשב עשבים עץ עצים עלה עלים שרש שורש שרשים שורשים פרח פרחים זרע זרעים פרי פירות גן גנים כרם כרמים חטה שעורה. Report selected-output rates and any-candidate upper bounds per section, and all section-matched nulls; ambiguous/common forms and uninflected-only matching limit specificity. Section association descriptive only.

Blind primary arm = Tanakh, clean inputs. Exactly 200 if eligible: 100 ZL + 25 each C9/C17/C11/C1. Select maxima/top-N identically as above, shuffle with OS entropy, random opaque IDs, source/variant/folio/score stripped. Save only ID, Hebrew model output, blank coherence 0–4, blank grammaticality 0–4, blank comments. Instructions define scales without source proportions. Separate sealed ZIP key, SHA256 commitment; never open or print decoded lines or key during QA. A seal is a procedural boundary (not encryption). No self-ratings. If source duplication makes blind collisions, retain them and log counts without reading contents. Medieval/noise analyses stay in automatic tables, not a post-hoc alternate blind panel.

Stop after verification and report. No translation claims, no chosen Hebrew meanings assigned to Voynich words, no changes to running Phase 4/5.
