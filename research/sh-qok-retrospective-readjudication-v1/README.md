# Applying the completed control qualification transparently

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Reassessed the specified, already exposed manuscript comparisons using the completed control follow-up while leaving the original files unchanged.

## What we found

The specified association comparisons passed their retained search corrections in both readings. The separate test of differences between contexts remained unqualified and still counted toward its original correction family.

## What remains unresolved

These are retrospective results, not new material or independent replication. The corrections do not account for every search made throughout the project's history.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
