# Does the sh-to-qok association survive an availability restriction?

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Asked whether a qok-starting next word was more frequent after sh than ch in the specified Currier A material, after removing structurally blocked followers.

## What we found

The separately qualified retrospective comparison passed in both main readings, with an effect of about four percentage points. This rules out the specified binary blocking explanation alone in these samples.

## What remains unresolved

The text was already exposed or uncertified as untouched. Other spelling, junction, and register explanations remain possible; this is not a grammatical or semantic identification.
