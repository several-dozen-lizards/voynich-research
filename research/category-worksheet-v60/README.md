# Trying competing interpretations without calling them translations

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Built an exploratory worksheet for substituting proposed categories into selected passages and comparing competing interpretations.

## What we found

Several broad assignments can be made structurally compatible with selected text. None earned a demonstrated semantic advantage, and unassigned words and uncertainties stayed visible.

## What remains unresolved

A plausible category pattern does not identify an ingredient, planet, procedure, or preparation. Useful progress would require consistent predictions and independently supported referents.
