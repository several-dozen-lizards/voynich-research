## Corrected adapter

`adapter.py` keeps relative layout metadata distinct from paragraph evidence. @,+,* do not set paragraph_start, paragraph_id or paragraph index. Only literal <%> provides explicit start evidence; <$> provides explicit end evidence. Unknown starts stay null. LSI1.5 lacks the newer dedicated start marker: lack of that evidence does not discard otherwise eligible individual loci. Safe fragments stop on page/reader changes, nonparagraph items, explicit ends, explicit starts, drawing/missing/spurious barriers. Safe-fragment identity is never advertised as a recovered paragraph. No borrowed ZL paragraph labels or post-end inferred starts. Ordinary types remain P0/P1/Pc/Pr/Pt, with per-reader state. This diagnostic is locus-local; no cross-line sequence or paragraph-window score is constructed.

## Gate order and stops

G0: confirm every new bound input and every old result artifact hash, including prior verification receipts. Any drift FAIL_PRESERVATION stops all chains.

G1: run authored fixtures after registration, using the actual corrected adapter. Every fixture must pass: @/* layout-only loci retain unknown start/paragraph state; known explicit paragraphs are not restarted by layout changes; end markers stop safe fragments without certifying next starts; H/U reader state stays isolated; page changes do not continue paragraphs; nonparagraph and drawing barriers prevent bridging. Validate canonicalization fixtures for EVMT comments, ! padding, -/= terminal markers versus internal drawing gaps, first alternatives, and exact dot/comma coordinates. Validate boundary comparison on identical text, one planted split/join, glyph substitution (must remain unaligned), and unknowns (held). No new manuscript data enters these fixtures. First fixture failure is FAIL_ADAPTER_ENGINEERING and stops G2/G3; no repair or in-place rerun.

G2: source-fidelity census, prior to the ZL/H boundary diagnostic. Compare local beta LSI H against the original Stolfi1.6e6 archive at exactly identified ordinary paragraph loci on non-ring source families, training and heldout. Original identity is (folio, numeric/alpha line ID, H), with source unit retained in the ledger; no fuzzy matching, renumbering, folio aliases or H substitutions. Duplicate identity, missing original identity, malformed source or unmatched required record is unresolved and fails. Other readers are not pooled. Original file's `{...}` comments are not glyphs; original terminal - is line end, = paragraph end, internal - is a major interruption. Original ! alignment padding is removed. IVTFF annotation comments and formatting padding are removed under their own rules; ligature braces retain components. Original weird/unknown glyphs, ambiguous alternatives and interruptions are HELD by a prospective symmetric rule, not repaired or silently bridged. Preserve all held records and reasons.

For each clean comparable source pair, require EXACT glyph-stream equality, EXACT dot/comma boundary positions/types, and exact original terminal '=' versus IVTFF <$> end-marker agreement. No post-hoc title-attachment or editorial exception map is admitted. Preserve original text-unit IDs and both raw spans so a mismatch can be assessed later. A conversion difference is an unresolved fidelity difference, not automatically proof that either editorial representation is wrong. Any unresolved difference gives FAIL_SOURCE_FIDELITY; missing original gives UNSUPPORTED_SOURCE_FIDELITY. Require at least30 clean compared loci across8 non-ring families; otherwise UNSUPPORTED. All source mismatches are reported together within this single census gate; none is an experiment or a direction score. All unresolved source records remain held if a future scope is proposed, but this registration does not select a favorable post-hoc subset to pass.

The source-census gate does not certify manuscript truth, historical H independence at every locus, or the beta conversion's unassessed unknown spans. PASS means clean non-ring paragraph source conversion meets this registered fidelity criterion. Do not reinterpret an ordinary-locus validation pass as circular/radial source qualification.

G3 (only after G1 and G2 PASS): descriptive boundary-disagreement census on strict clean held-out ZL/H ordinary paragraph loci, same RD family partition and ring-family exclusions. IDs must match exactly. Require>=30 eligible aligned loci and>=8 source families overall; otherwise UNSUPPORTED_DIAGNOSTIC_SUPPORT and stop before feature aggregation. They are descriptive annotations, not independently identified H scribes or new K3 gate claims. Retain training/heldout source split; no fitted models, permutations, significance tests, new direction scores, I measurements or language ranking.

For aligned loci, report shared boundaries, ZL-only boundaries, H-only boundaries, and dot/comma label differences. At a shared boundary, compare the final/initial transcription-unit pair under each reading, using the same13-cluster inventory. Record feature differences at shared boundaries. Spacing-exclusive edges are definitionally absent from one parse; do not present that tautology as a measured explanation. Counts and shared-edge feature differences are descriptive representation comparisons, not proof that transcribers created manuscript structure. No causal attribution or plaintext-space interpretation is permitted.
