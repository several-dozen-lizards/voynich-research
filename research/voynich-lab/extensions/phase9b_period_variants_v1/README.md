# Preparing a more careful historical month-name comparison

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Registered finite spelling-variant rules, distinct-month counting, language comparisons, and a bounded source census before new fitting.

## What we found

The retained deliverable is an incomplete source census and registered design. Calibration and annotation fitting had not run.

## What remains unresolved

Generated spelling alternatives must remain distinguishable from attested forms. This is not a negative language-identification result or a completed variant freeze.
