# Preparing the junction-feature calibration chains

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Bound constructed mechanisms, literal unit definitions, conditional comparisons, and stopping rules before the JX calibration.

## What we found

The associated Phase 0 result passed several engineering/specificity chains but failed the spacing-reference ordering chain. Unrelated passes did not repair that failure.

## What remains unresolved

Reference differences do not constitute a plaintext-space classifier or a language ranking. The unvalidated mapping PDF remained separate.
