# RD revision 1 — reading direction and boundary localization

Date: 2026-11-06. User authorized the proposed amendments, registration and Phase 0 only. The supplied `SPEC_USER_DRAFT.md` is retained unchanged. This side spec does not consume v10. This document and `rd_phase0.py` supersede the draft's conflicting seam, path, calibration and implementation details. Registration is `registration_v1/REGISTRATION.json`, created before generation, fitting or scoring; input and instrument hashes must match on execution.

## Questions and scope

Q1: paragraph-trained word-pair direction recovery in circumferential closed cycles and radial open paths. Q2a: localization of **any retained original line boundary** in a multiline cycle. Q2b: recovery of a **unique original line origin** in a single complete held-out line, only where length support exists. Q2a cannot qualify Q2b. No unique-start recovery is attempted on multiline loops. An old transcription boundary is a known synthetic origin, not authenticated historical intent. Q3 and S-p1 remain later analyses. No translation, glyph shapes, biological claims, personas, re-running other specs or overwrite of source transcription.

Phase 0 stops on the first failed/unsupported required gate; later gates are NOT_RUN. Failed bins below a qualifying L_min are underpowered rather than a global failure. Phase 0 success alone does not authorize Phases 1–4, and the visual annotation freeze must precede any real-ring score. Real ring vocabulary/order is never scored in Phase 0. The old draft's real-ring shuffle null is deferred to the target phase, not used for calibration. S-int means transcription-unit order reversal, not reflected glyph shapes.

## Frozen data and partition

Primary paragraph intake is `ZL_lines_corrected.csv`; raw ZL and LSI hashes remain bound. Primary target geometry comes only from the saved ZL inventory: word length, type, scribe, section. LSI is inventoried, not pooled or scored in this calibration. Foldout family is the digit part of a folio ID (all f72 panels together); fRos and f85/f86 are one rosettes family. All families containing a C/R target are excluded from both paragraph training and held-out calibration to prevent ring/paragraph folio leakage. Every remaining family is assigned train if the first 8 hex digits of SHA256(`RD-v1-split|family`), divided by 2^32, is <0.60, otherwise held out. The same partition applies to every signal. This is a new within-RD partition, not a historically unexposed corpus claim.

Ordinary types are P0/P1/Pc/Pr/Pt. Exclude spurious, missing, uncertainty-bearing lines (`has_uncertainty`), empty lines, non-ASCII-alphabetic cleaned words, and raw drawing interruptions `<->`/`<~>`. Frozen baseline comma splitting and first alternatives are inherited, but uncertainty-bearing lines are excluded rather than selectively repaired. Preserve a complete exclusion ledger. Eligible neighboring lines are joined only when same folio and consecutive explicit `line_index_in_paragraph`, with no paragraph start in the second line. Excluded lines break runs. Loci remain proxies for physical lines; this scope limitation is retained, not silently reconstructed.

## Signals (fit on training paragraph words only)

S-dir uses **joint** word-bigram probability ratios, equivalently D(a,b)=log((count(a,b)+0.5)/(count(b,a)+0.5)); equal normalizers cancel. Train within eligible lines and across consecutive eligible lines within the same paragraph. Unseen pairs contribute zero. Closed-cycle scores include the last→first edge and divide by n; open-path scores exclude it and divide by n−1. n=1 has no pair evidence; n=2 closed cycles always cancel. Absolute scores <=1e-12 are ties, worth 0 accuracy, never forced forward.

S-pos is a deterministic multinomial naive Bayes classifier over first/interior/last tokens of lines of length >=3, with add-0.5 feature smoothing and empirical class priors. Features are literal EVA codepoint n-grams 1–3 (with boundaries), word length, initial and final codepoint. The vocabulary is learned from training words only, OOV features ignored. First/interior/last labels are exclusive; short lines are excluded from this fit. Probability outputs are operational NB scores, not a claim of calibrated posterior probabilities. Continuous position is the probability-weighted mean relative position of the three training classes. Five training-family hash folds supply an out-of-fold diagnostic before the final full-training fit at the position stage; no hyperparameter selection. The scoring rule is frozen and does not change based on that diagnostic.

S-int uses the original lab's 13 clusters (`ch sh cth ckh cph cfh ii iii in iin aiin qo ee`), longest-match then ASCII single codepoints. These are fixed transcription units, not adjudicated glyph identities. Learn add-0.5 unit distributions conditional on initial/medial/final position; score a word by mean log likelihood, excluding length-one-unit words. Mirror by reversing the unit list, preserving each unit's rendering. S-p1 remains descriptive and unused for calibration selection or origin identification.

## Calibration generation and sealing

Seed 2026110601. Fixed bins [1,2], [3,5], [6,10], [11,20], [21,40], [41,80], [81,160], [161,1000000]; only inventory-occupied bins are required. For each occupied geometry bin, request 200 cases; select inventory rows in randomized repeated cycles so each target contributes equally within bin. This oversamples sparse lengths deliberately: results are conditional to bins, not independent trials or an empirical ring-frequency population estimate.

For each requested length n, candidate source windows begin at eligible held-out line starts and contain exactly n consecutive words within one paragraph run (the final line may be truncated). Match scribe+section if >=8 eligible source families, then scribe if >=8, otherwise all eligible source families. Every fallback is logged. Select the least-used candidate window, breaking usage ties randomly, to distribute support. Overlapping windows and repeat trials are allowed, disclosed and never treated as independent folios. Score uncertainty is assessed by source-family bootstrap. A supported bin requires >=30 distinct (source start, n) windows and >=8 held-out source families. Unsupported bins remain underpowered. Requested lengths with no windows remain unavailable; no replacement length or wraparound text is invented.

Each case has a random 50% reversal flag. Circular cases additionally rotate by a uniformly random word offset; radial cases never rotate. Store original offsets, source windows, direction flags, original line-boundary sets and unique-origin indices in `sealed/keys.json`; scoring reads only `stimuli.jsonl`. For circles Q2a accepts only line starts whose preceding word is the end of a complete source line, including offset 0 only if the sequence also ends on a complete source line. At least two such boundaries are required for a multiline localization trial. Q2b is a **separate** set of complete single lines, drawn in randomized order without repetition, with length >=6 and in an occupied circular bin. Each is independently reversed and rotated. A random 10% subset of direction cases is unit-mirrored as a separate copy with the same geometry and source-family labels; originals remain unmirrored for S-dir. Labels are not supplied to the scorer.

The key hash is sealed before scores; the key is opened by evaluation only after the corresponding scores file is saved and hashed in an event receipt. This is process separation/auditability, not cryptographic blinding against a malicious operator. Stimuli can be recognizable; neither the agent nor Re is claimed historically unexposed. No real-ring output is produced or inspected.

Latin control uses existing C1 `clean.csv` in source_word_start order, validating contiguous source spans; its relabeling is injective and its layout artificial. Flatten once; first 60% words train, a 128-word guard is discarded, remainder test. Divide the test sequence into contiguous 512-word source blocks; windows never cross blocks. These are source-span clusters, **not historical section labels**. Use the identical S-dir, length matching, reversal, circle/open-path edges, support and null pipeline. Source hand/section matching is unavailable for Latin and logged as not applicable. Latin tests direction only, not scribal line positions. A single source work limits transfer claims.

## Gates and statistics, in execution order

All family bootstrap intervals use 2,000 draws, equal sampling of families with replacement, pooling their cases, percentile 2.5/97.5% endpoints. Seeded separately by stage/bin. These are marginal clustered intervals, not a simultaneous confidence band. Wilson intervals are secondary descriptive checks. No seed retries, bin changes, new feature selection or null rescue.

1. **Direction and direction nulls**, for ZL circular, ZL radial, Latin circular and Latin radial separately. For each bin: recover the hidden flag from score sign. Report ties, distinct windows/families, pair coverage, accuracy and family-bootstrap CI. A bin passes recovery if supported, accuracy >=0.80, lower 95% CI >=0.65. L_min is the lower edge of the shortest passing bin, **not** permission to call every longer bin: only individually passing supported bins are eligible. Each geometry/corpus must have at least one passing bin, or the gate fails. Shorter/nonpassing bins stay underpowered. For every case independently shuffle the words once, retaining the hidden original reversal label; expected accuracy (non-tied only) is 0.5. Null acceptance requires >=100 non-tied trials, >=8 families, observed accuracy in [0.40,0.60], and the entire 95% family-bootstrap interval within [0.35,0.65]. Report binomial p values descriptively; p>0.05 is not an equivalence gate. Structurally uninformative bins (circles n<=2, paths n=1) have zero scores/ties and do not enter this null check. Failure or insufficient evidence in a required corpus/geometry null stops. All direction scores are saved before any key is opened. Evaluate/report every cell of this one batch, then stop before other stages if any required direction/null gate fails.
2. **Unit mirror**: on paired normal/mirrored copies, prefer the orientation with higher S-int mean. Ties are wrong; support >=30 distinct source windows, >=8 families, accuracy >=0.90 across pairs. This gates only the declared unit-reversal check. Failure stops.
3. **Any-line-boundary localization**: score s(w_i)+e(w_(i-1)) at each circular seam. Use sealed true direction for this isolated localization gate, so direction errors are not conflated with boundary learning. Report a separate end-to-end version using inferred direction. Choose uniformly among tied maxima with frozen RNG. At qualifying circular direction bins, success means within circular ±2 words of ANY retained boundary. Chance is the size of the union of those windows / n. Exclude chance=1 trials as uninformative. Require >=30 distinct windows, >=8 families, hit rate >=0.50 and lower family-bootstrap CI of (hit−chance)>0. Both isolated and end-to-end versions must pass. Null uses independently shuffled word positions with the original target boundary set held fixed: excess CI must contain zero with upper <=0.15 and lower >=−0.15. A maximum over rotations is never a significance test. No supported informative trials is gate failure.
4. **Unique line-origin recovery**: only complete single-line trials in qualifying circular bins; same ±2 rule and tie handling. Chance=min(n,5)/n. Require the same support, hit>=0.50, lower excess CI>0 and shuffled-null interval acceptance as stage 3. Report exact length support; no extrapolation to longer manuscript circles. No supported informative length bin is failure, not permission to export unique starts.
5. **Boundary-feature pairing null calibration**: for the first 100 eligible held-out multiline trials in qualifying bins, 199 independent within-sequence shuffles test the maximum seam feature score. Calibrate false positives using an independently shuffled observed sequence per trial. Tie-inclusive Monte Carlo p=(1+#null>=observed)/200. Require >=100 trials and observed false-positive fraction <=0.10 at p<=0.05. This is a test of unusually strong feature pairing, not unique original start. Any null false-positive gate failure stops. No real-ring shuffles are used.

The split/eligibility and candidate geometry support are not silently optimized. A gate can fail because the instrument, source support or null equivalence is inadequate; that is not evidence about the manuscript's reading direction. S-pos class diagnostics, held-out scores, and failures are saved only when their stage opens. Data generation can prepare later-stage stimuli before the first gate; later-stage scores cannot be computed after a failed gate.

## Later target phases remain closed

Retain draft predictions: ring line-position signature weaker but nonzero; majority transcribed direction; no seam prediction. Later Q3 uses paragraph-vs-label **binary** logistic decision log-odds (character n-grams 1–3, C=1, 5-fold folio-family grouping), with out-of-fold medians for reference groups and held-out ring projections; ring labels never train this axis. Distance is absolute difference of medians; the draft's half-distance thresholds define line-like/label-like/intermediate. This explicitly replaces the ambiguous three-class axis, and Q3 is exploratory where hand/section common support is absent. A separate three-class probe may only be descriptive. Real-ring statistics require a later executable freeze and authorization, not implied by this Phase 0 registration.
