# Phase 11 — plaintext-unit search, tokenization first

Registered 2026-10-27. New experiment; earlier gates and negative results are unchanged. Question: can a fixed, training-selected segmentation and context merge produce held-out unit statistics in a natural-language comparison band which the registered gibberish search cannot reach? No letter assignments, language identification, or translation. A pass is statistical compatibility under this instrument, never semantic evidence.

## Frozen bank, replication and splitting

Twenty replicates, seeds 11001 through 11020. These are split/noise/encoding replicates of fixed sources, not twenty independent texts. Use C1 Latin, C2 Italian, C3 German, C13 authentic abbreviated manuscript transcription, and Occitan from the already pinned Lindemann–Bowern Wikipedia corpus (modern genre supplement, not medieval Occitan). C1–C3 are original native clean.csv texts, C13 original clean.csv; Occitan is normalized by NFKD, removing combining marks, lowercasing, alphabetic words only, first 34,509 words. No selection on metrics. Native alphabets are preserved, no per-corpus injective relabeling before the published tokenizers. Existing C1–C3 clean tables retain their native alphabet.

Train/test are approximately half by whole source groups, fixed by SHA256(seed, group). C13 keeps whole physical leaves; C17 keeps source documents; borrowed-layout C1–C3/C7/C8/C9/C11 use contiguous blocks of 200 source words as groups, never fake manuscript leaves. Odd group goes to test. Real target groups are physical leaves with recto/verso/panels together. Report actual words, characters and groups in both halves; no word/type overlap purge. Training includes no held-out content or evaluation metrics. Each replicate receives fresh IID noise with the old frozen rates (substitution .021595507891541885, insertion/deletion .010565686968838526 each), including spaces; process each original line independently, never join across source documents. Exactly the same noise function and rates apply to all families. Clean views are diagnostic only; primary bands and gates use noisy views.

Positive: C1 and C2 separately encoded by original published Naibbe algorithm, both 52/78 decks, standard 17/36 respacing and original ambiguity rejection, optional space removal off. Encode first 34,509 output words, no repetition/padding, from each full frozen selected source slice; fail insufficient source. Capture actual accepted prefix/suffix spans including rejected draws, compare reconstructed ciphertext to author's output. Truth is private to boundary evaluation, never supplied to fitting. Noise propagates source chunk IDs at character resolution; surviving adjacent source glyphs with different chunk IDs define observable true boundaries. Inserted nonspace glyphs have unique IDs; substituted glyphs inherit the source ID; deleted chunks disappear. Evaluate internal nonspace boundaries only (spaces do not count as recovered boundaries); thus one-chunk words supply no easy true negatives. Report precision/recall/F1 and observable boundary count; no-boundary cases are NOT_ESTIMABLE. This evaluates recovery after the specified edit channel, not an assertion of recoverability of deleted information.

## Stage A — three fixed tokenizer families

T-Z uses Zattera's published SlotAlphabet character conversion (ordered multi-glyph replacements), NOT a fitted slot grammar and NOT slot-position-decorated symbols. Apply losslessly reversible replacements from the pinned fromEva source in order (ckh/cfh/cth/cph/ch/sh/eee/ee/iii/ii); retain every other glyph as RAW. Do not apply published lossy unreadable-character replacements. Record that this lossless fallback is an adapter, not an exact replication on unsupported symbols. No frequency or band-based selection.

T-N uses all distinct nonempty glyph chunks from the original published Naibbe tables across unigram/prefix/suffix and all keys; no letter/state/table labels are features. Choose a within-word segmentation by dynamic programming minimizing the sum of -log2 training chunk probabilities; probabilities are fixed from a first deterministic longest-match pass over TRAINING words, additive 0.5 over published chunks plus observed singleton fallback alphabet. Exact ties: lexicographic tuple of chunks. A held-out unseen singleton receives the same escape cost, is retained verbatim, and never changes fitted probabilities. This is one published-inventory adapter, not an assertion that published inventory makes segmentation unique. Report ambiguity and fallback coverage. Naibbe tables and Zattera's alphabet have prior Voynich exposure: NON-BLIND, including positives.

T-MDL uses a lossless within-word BPE path starting from singleton characters on TRAINING only. At each step merge the highest-frequency adjacent pair (lexical tie), nonoverlapping left-to-right. Evaluate every prefix from 0 through 64 merges (or stop when no pair has count >=2). Choose the minimum description length, not an entropy/band optimum. Score L = N*H0(tokens) + .5*(V-1)*log2(max(N,2)) + sum over new dictionary tokens [(len(token)+1)*log2(A+1)]. A is training singleton alphabet size, N token count and V active inventory. Fixed 64-merge cap is a search budget, not a desired letter inventory. Record complete path, selected prefix, cap exhaustion and ties; no claim of global MDL optimum. Held-out unseen glyphs remain lossless singleton escapes. All tokenizer families are run/reported; no best-on-test tokenizer replaces the others.

## Stage B — distributional merging, training only

For each TRAINING chunk type construct directed left/right neighbor counts including explicit word-edge symbols; no line-crossing counts. Average-linkage clustering of square-root normalized context vectors using Euclidean (Hellinger-proportional) distance supplies a fixed context-similarity hierarchy (lexically sorted symbols; deterministic SciPy implementation/version sealed). Evaluate all K=1..V cuts, including singleton cut, by MDL. For each cut, L = sum_cluster count*H(context|cluster) + sum_cluster chunk_count*H(chunk|cluster) + .5*K*(D-1)*log2(max(M,2)) + V*log2(K+1). D is context feature count, M total context events. The residual chunk-identity term prevents treating erased distinctions as free compression. Choose minimal L; exact ties choose larger K, then canonical lexical mapping. No natural-language metrics enter. Held-out unknown chunks remain distinct unmerged symbols; report OOV counts. Return both pre-merge and post-merge held-out metrics and saved fitted maps. No known plaintext labels enter clustering.

## Metrics, bands and gates

Notation is explicitly h1=H(U), h2=H(U_next|U), bits/unit (Lindemann–Bowern convention; NOT old lab's h1/h2 order labels). Estimate by plug-in counts within observed words; do not count whitespace as a unit, and do not cross word or line edges. Report inventory V observed on held-out, h1, h2, h2/h1, OLS log(frequency) on log(rank) slope across ALL unit types (lexical tie), mean observed word length in units, and positional entropy H(U|position-bin), using bins initial / interior / final / singleton. Also report each bin's entropy and count. Mean word length describes observed spaces, not inferred plaintext word boundaries. Zero h1, fewer than two unit types, no adjacent pairs, or any nonfinite metric makes the vector NOT_ESTIMABLE and cannot pass.

For each tokenizer and pre/post stage, band is the coordinatewise 2.5th–97.5th percentile (linear interpolation) of the 100 natural-control replicate vectors, equally weighted by five source families, 20 each. All seven coordinates must be inclusively inside their corresponding intervals to land in band. These are marginal 95% intervals, NOT a simultaneous 95% confidence region; report natural-control self-coverage. Also report a raw-letter identity reference on the same noisy held-out natural sources so a transformed-unit band cannot silently be called a literal plaintext-letter band. Primary compatibility requires post-merge membership in BOTH its identical-pipeline natural band AND raw-letter band; pre-merge is fully reported. This conservative literal-letter anchor prevents vacuous shared collapse. Freeze both before calibration.

Positive calibration requires, in EACH language x deck cell for a tokenizer, boundary F1 >= .8 AND primary post-merge membership in at least 16/20 replicates (80% fixed operational recovery criterion). Boundary and band success must occur in the same replicate. A tokenizer is eligible only if all four of its cells pass. Global calibration requires at least one eligible tokenizer; only eligible branches may later score the target. This eligibility rule is fixed before controls, not a post-result subset rescue. Report all 12 cells, including failures. No calibration by the known-letter oracle. Specificity still tests the union of ALL three branches, including ineligible ones.

For EACH negative family, a replicate is a hit if ANY of the three tokenizers has primary post-merge membership. This calibrates the full search opportunity, not just a convenient branch. If hits >=4/20 (20%), NON_DISCRIMINATING and STOP. Report each branch plus family union, binomial intervals only as descriptive because source/noise replicates are dependent. Complete the sealed control bank even when a failure is evident; no Voynich access or new sweep. Natural-control and negative disagreements are results.

## Conditional secondary contract

For each tokenizer that passes BOTH primaries, use its post-merge A/B streams. One-to-one support requires equal training inventory cardinalities, all training types present in held-out, and no held-out OOV; otherwise NOT_ESTIMABLE, never pad/drop units. Build directed within-word bigram matrix G and unigram p on training halves, separately L2-normalize G and p. Align by maximizing Q=.5*<G_A,P G_B P^T>+.5*<p_A,P p_B> using SciPy FAQ, 100 iterations, tolerance .001, starts rank-frequency, identity completion and barycenter, plus five seeded randomized doubly stochastic starts. Pick maximum TRAINING Q, lexical tie. Unit strings only define deterministic ordering; identity completion is not a proposed letter assignment. Score Q on held-out halves with frozen mapping; no test optimization. Save directed-context and frequency components separately.

Calibrate first on 100 paired replicates (seeds 21001..21100): use noisy C1/C2/C3/C13/Occitan raw-letter streams, 20 per family. SHA-grouped disjoint halves as above. Apply two independently seeded injective unit relabelings, retaining oracle maps privately. This is a pure one-to-one two-table synthetic control, not proof Naibbe is bijective. Compare paired SAME_SOURCE_TWO_TABLES, SAME_SOURCE_ONE_TABLE, DIFFERENT_SOURCE_TWO_TABLES (next language cyclically), and WITHIN_WORD_SHUFFLED_TWO_TABLES. SAME_SOURCE_ONE_TABLE is a positive for shared profiles, not a negative for shared language; its identity mapping baseline must be reported and cannot establish two distinct tables. Require >=80/100 SAME_SOURCE_TWO_TABLES to recover at least .8 oracle mapping token mass and exceed the 95th percentile of the paired different-source/shuffled scores. Require each negative class to falsely exceed that SAME_SOURCE_TWO_TABLES lower 5th percentile in <=5/100 cases. Missing/unsupported synthetic cells fail calibration. These fixed thresholds must all pass; no retuning.

Then compare held-out target Q against 100 matched control-pair Q scores for EACH C7/C8/C9/C11/C17, learned/scored by the identical algorithm on disjoint source-group halves, relabeled as two tables. Use the first available target-count prefix of each half only if enough source exists; otherwise explicit NOT_ESTIMABLE, no padding. All five control families must be estimable. Target must exceed every family 95th percentile, with plus-one upper-tail p and Holm correction across eligible tokenizer x five family comparisons at .05. Also report native identity and rank-frequency baselines. This tests profile alignment, not plaintext identity or distinct historical cipher keys. The implementation and its conformance tests must be sealed before these synthetic scores; primary outcomes may not alter this contract. No letter values or semantic labels leave oracle diagnostics.

## Prior work and limitations

Lindemann & Bowern motivate alphabet/segmentation sensitivity and entropy comparisons; no reported metric band implies language.
