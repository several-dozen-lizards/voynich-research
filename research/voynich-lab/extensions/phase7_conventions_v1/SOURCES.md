# Source and scope receipts

Physical collation: Rene Zandbergen, Layout of the manuscript, https://www.voynich.nu/layout.html ; descriptions at https://www.voynich.nu/q01/index.html through q20 (16 and18 missing). Retrieved through the web tool; factual quire/folio descriptions and citation URLs preserved in sources/. Standard nested collation yields conjugate pairs at symmetric leaf positions; unusual/missing-sheet descriptions are recorded explicitly. This is the extant physical map, never an original reading-order reconstruction. Zandbergen describes first-hand conservation observations and explicitly distinguishes disturbed binding from a recovered original order at https://www.voynich.nu/extra/sp_origin.html .

Known missing leaves12,59-64,74,91-92,97-98,109-110 are retained in the physical-map ledger as missing. They are not synthesized. Folios85/86 are one physical foldout sheet with nonstandard panel geometry. Existing transcribed panel identifiers are pooled by physical leaf side; only the common observed ZL/H page set enters the matched analyses/controls.

Secondary order sources: Nick Pelling (2022), Quire20, order from chaos, part1 evidence and part2 suggestions, https://ciphermysteries.com/2022/12/20/quire-20-order-from-chaos-part-1-evidence and https://ciphermysteries.com/2022/12/22/quire-20-order-from-chaos-part-2-suggestions . These include a Bunn2010 proposed center fragment111r,111v,108r,108v, proposed subquire groupings and a106v-to104r adjacency; none is silently expanded to a complete order. Pelling2006 Q13 reversal is discussed at https://ciphermysteries.com/2010/06/15/the-four-main-voynich-ghosts ; the secondary interface https://voynich.kiltau.com/bifolio/bM2 displays a full leaf ordering but primary page orientations were not verified. VoynichViews2015 Q13 was found by cross-reference at https://voynichviews.wordpress.com/2015/10/10/voynich-manuscript-re-ordering-the-folios-in-quire-13/ ; exact primary sequence not retrieved.

Colin Layfield and Lisa Fagin Davis (2026), Singulion Structure and the Voynich Manuscript, Digital Medievalist, DOI https://doi.org/10.4000/16k0a ; publisher https://journals.openedition.org/digitalmedievalist/2331 served an Anubis bot challenge. No challenge was bypassed or missing sequence invented. The independent image resource https://quantumlynxresearch.com/resources/singulion_images explicitly names sheets by CURRENT nesting positions, not an established original global order; download requires an email request, which was not made. These sources remain hypotheses/source limits in ORDER_REGISTRY.json.

Naibbe control backend: original pinned Greshko code and glyph tables, reused read-only from ../phase7_two_table_v1. Greshko2025, Cryptologia, DOI https://doi.org/10.1080/01611194.2025.2566408 ; git commit719f2f4c4d1eacf95fabf48381cd84fc6cd94279. Original modified-MIT/citation text remains in that author's source and notices; source hashes frozen here. The published glyph tables were designed using Voynich statistics and are NOT blind controls. New calibration uses fixed40:1 mixture profiles over these glyph maps, with respacing17/36, never target fitting or disjoint output scripts.

C1 Latin and C2 Italian: unchanged normalized plaintext streams, source slices and provenance from Phase7. They are public-domain historical editions with uncorrected OCR; old source receipts remain preserved. Five seeds and paired clean/noise views are not independent texts. The existing IID transcription-noise rates/injector are reused unchanged.

Slot grammar: pinned mzattera/v4j SlotAlphabet.java, commitdd061388e2e9e5330abcad84b5755195c05d01d2, GPL-3.0. Original Java/license and adapted prior Python source retained; only the source-path import changes in slots_adapter.py. All words count in coverage, including unstructured/unreadable. This is an already Voynich-derived grammar, not independent historical evidence.

ZL/H text files are hashed for provenance but their text features remain closed until every calibration gate passes. Only identifiers/layout/metadata are inspected before calibration. All prior Phase7/C12/C16 records remain read-only. Full source/code/layout/control/truth hashes and model likelihood receipts are retained.
