# Code for a circular-only boundary follow-up

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Bound a follow-up focused on longer circular calibration examples after the first direction study stopped.

## What we found

Its associated result could locate some retained boundaries but lacked supported unique-origin cases. The separate follow-up stopped at that required gate.

## What remains unresolved

A likely boundary is not necessarily the original start of a ring. Radial work and real-ring scoring were not opened.

## What is in this folder

- [PROTOCOL.md](PROTOCOL.md): the rules, intended scope, or pinned setup.
- [verify.py](verify.py): checks or qualification evidence; read the scope of the gate.
- [followup.py](followup.py): implementation or checking code.
- [registration/](registration) (4 archived files): Study rules, source/geometry registration, or pinned inputs. Read the timing and amendment receipts before assuming a stage was complete.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
