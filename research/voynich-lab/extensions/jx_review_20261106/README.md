# Reviewing the junction proposal and candidate-language register

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Checked source-backed premises, operational predictions, and the distinction between an experimental proposal and an asserted mapping.

## What we found

The review preserved source gaps and corrected drafts rather than treating the proposed Latin mapping as accepted evidence. It separated unit associations from phonological and causal claims.

## What remains unresolved

This was a bounded documentary review, not a complete historical attestation project or an experimental calibration. A candidate list is not evidence that a candidate is the language.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code. Compressed `.gz`/`.xz` files retain the original bytes; the repository restoration helper can unpack them. HTML reports may require a local browser rather than GitHub’s file viewer.
