## Held-out graph alignment

Pool foldout panels to physical leaf sides. Keep both sides/panels AND physical conjugates together in five fixed bifolio-grouped folds: stratify physical sheets by known A/B composition (A-only, B-only, mixed), shuffle sorted sheet IDs in each stratum with SHA256(1729,sheet_fold,stratum), cycle folds0..4. Same fold map across controls and later ZL/H. Fold construction uses identifiers and known partition composition only, never text/statistics; preflight requires both halves in every fold. Each fold learns its A-to-B mapping and vocabularies from its complement and evaluates on held-out sheets. A/B support must exist in every train/test half; otherwise NOT_ESTIMABLE and qualification fails. No metadata features.

Build native word co-occurrence graphs from whitespace tokens, within each line, window2, symmetric weighted counts. Vocabulary is the48 most frequent TRAINING tokens per half, frequency ties lexical; pad missing slots with zero-mass dummy nodes. Preserve/report all token counts and core token coverage. Unrepresented types are not secretly merged into a matching OTHER node. Remove graph diagonal for the structural term; exact token frequencies supply the diagonal/frequency term. L2-normalize off-diagonal adjacency G and frequency vector p separately. Empty graphs/signal are NOT_ESTIMABLE. This is a finite core-word graph approximation, not lossless inference over every unit or a guarantee of bijective real encodings.

Learn a bijection using SciPy FAQ graph matching on M=sqrt(.5)*G+sqrt(.5)*diag(p). Maximize its Frobenius inner product under permutation. Fixed candidates: rank-order permutation and native-identity completion, plus FAQ runs initialized from rank order, native completion, barycenter and randomized doubly-stochastic start. maxiter100, tol1e-3; fixed seeded RNG; never increase budget after outcomes. Choose maximum TRAINING objective, exact ties lexicographic permutation. Report iterations/budget endpoints; FAQ is approximate and no global optimum is claimed. Published-key word collisions can violate bijectivity; calibration tests this limitation rather than correcting it.

On held-out data, compute Q=0.5*<G_A,P G_B P^T>+0.5*<p_A,P p_B>, multiplied by sqrt(core_token_coverage_A*core_token_coverage_B). Report graph and frequency components separately. Compute native-identity Q0 using literal shared word strings only (unmatched rows/columns remain unmapped; no optimized completion for this baseline). Primary learned-mapping gain D=Q-Q0. Average Q and D equally across the five held-out folds; no selection on test scores. Report mapped core vocabulary/edges, coverage, permutations, source dictionaries and train/test scores. Rank-frequency contributes through mapped token-frequency agreement; no raw glyph/length/section/hand features enter this score.

## Shuffled-page nulls

Reordering pages within fixed A/B halves leaves pooled graphs unchanged and is NOT a valid informative null. Therefore “shuffled pages” means reassign A/B labels among whole leaves within each fixed sheet-fold and observed-page-count stratum, preserving A/B leaf counts and recto/verso/panel attachment. Physical leaves/conjugate folds do not move across train/test. All leaves in the original known A/B map have a uniform known label; assert this from metadata before registration. Each of99 null assignments refits vocabularies AND mappings from its training complement, then scores its held-out halves with exactly the same algorithm/seeds/budget. Save assignments, Q/D, plus-one upper-tail p=(1+#null>=observed)/100, null spread and duplicate/unchanged assignment counts. Constant null is NULL_INVARIANT, not evidence. Report both Q and D nulls; calibration's directionality gate uses D. This null tests relation to the A/B partition, not a uniquely cipher-caused effect; content/layout can remain relevant and are challenged by controls. No order/quire-coherence/book-wide-conjugacy inference.

## Development classifier and hard qualification gate

Development uses only the two saved scores (Q,D). Standardize each coordinate by development mean/SD (zero SD becomes1), fit equal-prior nearest-centroid categories ONE_KEY, SAME_TWO_KEYS, DIFFERENT; exact distance ties alphabetical category. No hyperparameter tuning, feature additions, alternative classifiers or label inspection of qualification scores. Freeze the learned scaler/centroids, all development outcomes and hashes BEFORE qualification scoring. This classifier is an operational separation check among these specific controls, not a probability of plaintext identity or a translation claim.

Evaluate all160 qualification datasets. For EACH base-plaintext x key-orientation x view x original control-class cell (32 cells, five seeds), require at least4/5 correct category predictions and at most1/5 false SAME_TWO_KEYS classifications among the negative classes. SAME_TWO additionally requires upper-tail D-null p<=.05 in at least4/5; SAME_ONE requires no more than1/5 such rejections. DIFF controls may require remapping simply because keys differ; their rejection status is reported rather than mislabeled a false positive for plaintext identity. Category separation must distinguish them using Q and D jointly. Missing/nonfinite/not-estimable scores or failed fits fail the affected cell. No aggregate success can override any failed cell.

## Within-quire physical similarity (user-selected output)

Use MAPPED GRAPH SIMILARITY BETWEEN CONJUGATE LEAVES, not inferred cluster/A-B labels. For each tested quire, learn the same graph mapping and vocabularies using all OTHER quires, excluding every tested leaf. All leaf profiles inside that quire then share one held-out mapping, preventing fold-specific mapping/vocabulary similarity from favoring conjugates. Map B profiles into A coordinates; leave A profiles in A coordinates. Null:1999 permutations of whole leaf profiles WITHIN the SAME quire, retaining the quire's frozen mapping and leaf support; plus-one upper-tail p. Constant nulls are explicitly invariant. No book-wide shuffle or quire-coherence statistic is computed.
