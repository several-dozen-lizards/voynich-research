# Pre-registration decisions

- This user-authorized run completes and calibrates only the later Latin-script month-annotation track. It leaves both native-script tracks closed. It stops after calibration, even on PASS, matching the user's requested stage. The original source audit is preserved, not rewritten as a completed four-language herbal lexicon.
- Forty filled month/language cells are a bounded candidate list, one cited form per cell, not all possible historical synonyms. Forms were selected by source evidence before scoring; no language is selected by target fit. Source selections, regional/case/spelling limitations, dates and uncertainty are explicit in PERIOD_NAMES.json. The dictionary/reference editions are not represented as new diplomatic fifteenth-century transcriptions.
- The 1495 Italian headings were inspected directly in the saved images. Transcribing a printed heading (including long-s→s) is source collation, not spelling correction to a desired name. Magio, Giugnio, Septembre, Octobre, Nouembre and Decembre are not modernized. Raw OCR and facsimiles are both retained; OCR errors are not treated as historical spellings.
- Raynouard's December heading is visibly Desembre in the printed source despite corrupt OCR. The source reading and image locator are retained explicitly. This is source verification, not an outcome-based name amendment. Earlier tentative OCR leads in the initial source audit remain unchanged.
- German wintermonat is included for both November and December, with its documented semantic ambiguity. The ten German forms are regional historical comparators, not a reconstructed single dialect or an exclusive calendar nomenclature.
- All language/encoding choices, parenthesis alternatives and name normalization are frozen before synthetic generation. There is no target-derived character substitution or fit in source assembly. The later annotation spellings were already seen and publicly collated, so no blind-reading claim is made.
- The published Naibbe codebooks require a distinction between plaintext spelling normalization and ciphertext symbol identity. Applying j/k/w spelling replacements to encoded glyphs would modify the codebook. Every synthetic and annotation label uses the same ciphertext cleaning; every candidate name uses the same plaintext normalization across all families.
- Naibbe is explicitly a six-fixed-table subfamily. A stochastic mixture is outside this registered model, rather than hidden extra per-label freedom. Preserve collisions with rejection off. Table identity must be uniquely recovered in positive calibration; ambiguous table maxima are not counted as recovered.
- Exact full-name matching, twelve-item support, a single consistent mapping, exact finite search and max-over-families/languages are used for real and every shuffled assignment. No coverage factor is used. This avoids silently carrying the Phase 8 coverage multiplier into a different test; it does not claim that name length has been controlled away.
- The source templates induce two optional literal positions for September and one for October/November in calibration, matching the annotation-ambiguity pattern while retaining the true complete synthetic string. All alternatives travel as a bundle in nulls. No arbitrary missing-letter restoration, edit tolerance or manual abbreviation expansion is introduced.
- Mapping truth remains separate from fitting. Generating-language/family recovery evaluates a fit already computed without truth; selected-family ties are reported because positional substitution includes monoalphabetic substitution. No unseen alphabet entry, stochastic deck schedule or unique Naibbe segmentation is claimed recovered.
- All 32 cells must pass the declared five-seed recovery/rejection and negative-rejection gates. Preserve unsuccessful recovery, invariant nulls, scorer exceptions and exact-search failures without rescue. All 320 fixed datasets are finished for supported diagnostics; no parameter/lexicon/model changes follow outcomes.
- Prior download failures are preserved. Successful sources were obtained through public archive page-image endpoints, raw public-domain texts, institutional pages and saved web extracts; a web extract is not mislabeled as original HTML. Source certificates were not disabled to work around failed hosts.
