# Phase 0 decisions — 2026-10-26

Historical Phase 0 decisions follow; Phase 1–3 amendments at the end supersede them where explicitly stated.

- Stop at Phase 0 as requested. Controls, tokenizers, model-free experiments, training, and analyses are deliberately unimplemented until this checkpoint is reviewed. No cloud inference or training; network use was only source lookup/download.
- Freeze the catalog-linked ZL3b-n (version 3b, IVTFF 2.0) and beta LSI_ivtff_0d (IVTFF 1.5). This is the requested full interlinear source, not the single-transcriber IT extraction. Hashes in config are checked before parsing. Retain source bytes untouched; no inferred redistribution license.
- Decode source bytes as Latin-1: LSI has legacy non-UTF-8 bytes in commentary. CSVs and reports are UTF-8. Raw text in each row is the complete logical-locus payload after trimming format padding; raw source bytes and source-line number preserve exact physical formatting.
- One row per locus and transcriber. These are not guaranteed whole physical lines. Keep same-line segments separate and keep suffix IDs such as f112v.44a. Physical-line registration across ZL/LSI is not established. The requested line_index_in_paragraph is a zero-based locus index, not a physical-line index, and null when no explicit start is available.
- Preserve transcriber IDs without pooling. In LSI, D/G/I/Q/M are unfolded alternative choices, not independent raters. Retain them in CSVs/counts; exclude from primary agreement. H is Takahashi; F is Friedman; keep their readings separate. Other historical readings may also share ancestry; no independence assumed.
- Page variables reset at every page header. Text tags override within page/transcriber. Keep section code and mapped name; missing variables and unset @ values become null. LSI $H means Currier's hand (as documented in its own introduction), so retain it in currier_hand and leave hand_scribe null. ZL $H means Davis's hand; ZL $C is Currier's. Do not import newer metadata into older files silently.
- Labels are generic locus type L, including Lx extraneous writing. Keep subtype and all records; do not silently discard marginalia. Circular/radial text is not automatically a label. Explicit ! locator is flagged spurious. Later analyses must select running text and labels explicitly.
- Use explicit <%>/<$> paragraph markers only. Without a known start, paragraph index/start status remain null; do not infer paragraph starts from page starts or from the line after an end. For paragraph loci, is_para_end records marker presence, not an adjudicated physical paragraph boundary. Non-P paragraph fields are null. Historical paragraph boundaries remain source-specific.
- Clean first bracket alternative (support : and legacy |), remove ligature braces while retaining constituent strokes, map each high-ASCII @ddd; code and unreadable ? run to one U+FFFD UNK. Unsupported nonalphabetic marks become UNK rather than vanishing. Ligature geometry and alternatives survive in text_raw. No claim that EVA code points are glyphs.
- Manuscript spaces are dots and commas (both split in the baseline); drawing interruptions <->/<~> imply a word separator. Other inline comments/tags are removed from clean text. Physical whitespace is formatting and removed. Legacy ! alignment padding is deleted; % missing stretches become UNK and make an agreement pair ineligible. This spacing/unknown policy is frozen before controls and must also be used or explicitly adapted/documented there.
- Count all preserved words, including UNK-bearing words; character counts exclude word spaces. Report every LSI transcriber separately. Do not multiply manuscript size by pooling interlinear versions. Per-section CSV contains counts and vocabularies; missing_metadata.csv records all requested nullable metadata.
- Primary agreement uses exact Levenshtein distance on same-locus LSI pairs, normalized by maximum clean length, including normalized spaces. Unknowns on opposite sides use different sentinel values so they never earn matching credit. Exclude alternative branches, missing spans, spurious loci and empty readings with explicit reasons. Pool distances/denominators, and report each transcriber pair. All candidate pairs are retained. This estimates sensitivity to historical readings, not ground-truth error, independence, full manuscript coverage, or uncertainty in model bits/token. Do not compare its percentage directly with model seed variance: future phases need transcription reruns in the same metric.
- Default shell Python is 3.10.6; use bundled Python 3.12.14 for this 3.11+ project. Phase 0 requires only the standard library. PyTorch is absent from that runtime; no package install, GPU check or training was attempted at this checkpoint.
- Preserve failed initial run folders: first discovered legacy encoding, second discovered alphabetic locus suffix. Parser now handles both; no rows silently skipped. Failure receipts accompany those folders. Initial network access required the authorized sandbox network retry; both raw files downloaded successfully.
- Two preliminary agreement runs were invalidated when independent dynamic-program verification exposed an optimized edit-distance bug. STATUS.txt marks both invalid; no preliminary values are evidence. The corrected implementation passes 500 seeded random comparisons and 200 sampled real-source pair comparisons against independent dynamic programming. Rebuilding also checks deterministic CSV hashes.
