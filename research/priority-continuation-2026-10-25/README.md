# Preparing the next controlled tests

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Prioritized published-key intake, image/text pre-join rules, and B/C adapter primitives while parking the role-weighting variants.

## What we found

Engineering checks passed, but all three screened published keys stopped at intake without scientific scoring. Missing ratings and provenance still blocked the image/text join at this checkpoint.

## What remains unresolved

Engineering parity did not replace real-support qualification. Later completion work is preserved in a separate continuation folder rather than retroactively changing this report.

File formats: JSON stores structured values or settings; JSONL stores one event/trial record per line; CSV/TSV stores tables. Python and JavaScript files are code.
