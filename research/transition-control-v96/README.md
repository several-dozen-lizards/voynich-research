# Does one-word-gap order exceed immediate-transition structure?

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Held each readable span's endpoints, word inventory, and immediate sh/qok/other transition counts fixed while testing the longer-gap contrast.

## What we found

No gap result passed the retained broad correction. The exact null had real variation and adequate numerical resolution, so the old rank-floor explanation did not apply here.

## What remains unresolved

The test fixes the adjacent association by design and cannot erase or retest it. Failure to detect a residual does not prove that immediate transitions fully explain the text.
