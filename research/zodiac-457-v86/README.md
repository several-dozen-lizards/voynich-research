# Can the scorer recover the historical degree-table pattern in controls?

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Ran a separate constructed-data qualification for the male/female degree table using the unchanged full-search scorer.

## What we found

All seven frozen gates passed, including noisy and partly missing planted signals and several nuisance controls. This strengthened coverage of that table within the authored simulation scope.

## What remains unresolved

It did not score any manuscript alignment or held-out sign, establish a historical identification, or guarantee sensitivity to the actual ambiguous images.
