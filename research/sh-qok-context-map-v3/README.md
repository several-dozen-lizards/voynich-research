# Mapping the association across contexts

> Plain-English reading guide to the archived snapshot. The linked reports contain the full rules, results, and qualifications. This guide is editorial material added after the original archive.

## What we tested

Compared sh/ch-to-qok effects across manuscript contexts using separate readings and explicit support and control checks.

## What we found

Some retrospective panels passed, including starred text in both readings; other apparently positive effects were blocked by failed null qualification. The descriptive map retained all these differences.

## What remains unresolved

A large-looking effect cannot rescue a failed comparison instrument. Context variation does not identify grammar, meaning, or a scribe-independent mechanism.
